# React Quiz App

An interactive quiz application built with React, JavaScript, HTML, and CSS.

## Features
- Interactive quiz questions
- Score tracking
- Dynamic user interface
- Responsive design

## Technologies
- React
- JavaScript
- HTML (JSX)
- CSS

## Getting Started

1. Clone the repository.
2. Install the dependencies:
   ```bash
   npm install
   ```
3. Start the development server:
   ```bash
   npm run dev
   ```
4. Open the local URL displayed in your terminal.
